# Asif Print Hub

Free-first browser toolkit for print shops, cyber cafes, students and local businesses.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Deploy free

Use GitHub Pages, Cloudflare Pages, Netlify or Vercel. Build command: `npm run build`. Output: `dist`.

## Included

React/Vite app, image resize, image-to-PDF, PDF merge, UPI QR, resume/biodata exports, poster/application/shop promotion document maker, government-jobs demo section and mock test.

The core file tools process files in the browser. Windows silent printing requires a local print agent; a normal browser cannot reliably perform silent printer access.

Government-job data in this starter is demo data and must be replaced with verified official notices before publishing.

ID/document formatting is a convenience tool and does not create or validate official government documents.
